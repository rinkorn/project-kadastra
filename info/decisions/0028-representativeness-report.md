# ADR-0028: Отчёт репрезентативности — распределение ЦОФ по всей сетке vs обучающая выборка

**Статус:** Accepted
**Дата:** 2026-08-20
**Реализует:** [эпик 001](../epics/001-grid-as-tsorf-infrastructure.md), этап 5
**Источник методологии:** [grid-rationale.md](../grid-rationale.md) §2 п.5

## Контекст

Методология (§2 п.5) требует проверки репрезентативности: «корректная репрезентативность — совпадение распределений значений ЦОФ на выборке и генеральной совокупности» (не совпадение min/max). До эпика 001 это было невозможно: ЦОФ считались per-object, «генеральной совокупности» не существовало. Сетка Слоя 1 (ADR-0027, 177 131 ячейка × 119 ЦОФ) впервые даёт полное распределение по территории — проверка стала cheap win'ом: обучение не нужно.

## Решение

1. **Популяция** — все ячейки Слоя 1 res 10 (6 feature_set'ов, join по `h3_index`).
2. **Выборка** — объекты gold (`valuation_objects`, 4 asset_class) join'ятся к ячейке через `add_h3_index(res=10)`; **дубли ячеек сохраняются** — ячейка с десятью объектами весит вдесятеро, это и есть распределение выборки. Сравниваются **сырые значения ячеек**, а не overlap-weighted объектные колонки — обе стороны сравнения тогда одна физическая величина.
3. **Метрики на фичу** (`kadastra/etl/representativeness.py`):
   - **PSI** (population stability index): бины — децили распределения сетки с открытыми концами, epsilon 1e-4 для пустых бинов. Пороги индустриальные: `<0.1` ok, `0.1–0.25` moderate, `≥0.25` shift. Константная популяция → PSI не определён (`nan`, вердикт `n/a`).
   - **KS-statistic** (`scipy.stats.ks_2samp`) — effect size. p-value при N~10⁵ номинален (всё «значимо») и приводится только для полноты.
   - **Coverage** — доля ячеек сетки, покрытых выборкой.
4. **Разрезы**: `overall` + per `asset_class`.
5. **Артефакты** (в `data/`, не в git): `data/gold/representativeness/region=…/resolution=10/data.parquet` (long-format: feature_set, feature, segment, n, coverage, ks_stat, ks_pvalue, psi, verdict) + `report.md` рядом. Запуск: `uv run python scripts/build_representativeness_report.py`.

## Результат первого прогона (2026-08-20)

**Покрытие**: выборка покрывает 19 667 ячеек из 177 131 (**11.1 %** территории); per-class: apartment 0.5 % (802 ячейки), commercial 5.1 %, house 4.8 %, landplot 10.6 %.

**Вердикты PSI** (119 ЦОФ, overall): 66 ok, 4 moderate, **49 shift**. Картина стабильна во всех классах.

**Топ-сдвинутые** (overall): `commercial_within_800m` (PSI 6.1), `walk_dist_to_tram_stop_m` (4.9), `dist_to_tram_stop_m` (4.9), `dist_metro_m` (4.6), `dist_entrance_m` (4.6), дальше — дистанции до POI (hospital, kindergarten, park, bus_stop, supermarket, pharmacy, restaurant) с PSI 3.0–3.7.

## Интерпретация

Сдвиг **ожидаем и объясним**: объекты НСПД сосредоточены в населённых пунктах, а сетка покрывает всю агломерацию, включая пустую межселенную территорию. Поэтому «дистанция до инфраструктуры» у объектов систематически меньше, чем у случайной ячейки территории — это не баг сэмплирования, а утверждение «модель обучена на освоенной части территории».

Операционные следствия:

- **Экстраполяция**: предсказания для ячеек вне освоенной зоны (89 % сетки) — экстраполяция модели; интерпретировать с осторожностью. Отчёт даёт формальный список фич, по которым выборка не покрывает территорию.
- **Не «чинить» сэмплирование механически**: довзвешивание сельских ячеек без объектов бессмысленно — там нет target. Репрезентативность по методологии — свойство **обучающей выборки относительно оцениваемого фонда**, а не всей территории; фонд оценки и есть освоенная зона.
- **Baseline для будущего**: при расширении выборки (новые классы, регионы, сделки) отчёт пересчитывается одной командой и показывает, что изменилось.

## Границы

- Сравнение по сырым значениям ячеек (centroid-привязка объекта); overlap-weighted колонки объектов в сравнении не участвуют.
- Темпоральной оси нет (блок 6, ждёт трек 1) — репрезентативность «на сегодня».
- KS p-value не используется для выводов (номинален при N~10⁵).
