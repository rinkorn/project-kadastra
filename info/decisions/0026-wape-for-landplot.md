# ADR-0026: WAPE для земли (landplot)

**Статус:** Accepted
**Дата:** 2026-08-17 (обновлено 2026-08-18 — log-таргет откачен)
**Реализует:** [ADR-0016](0016-quartet-of-models-and-loss-on-simplification.md), блок 5 — корректная относительная метрика для класса с мелким знаменателем ₽/м².

## Контекст

В ADR-0016 зафиксировано, что MAPE на landplot «структурно зашумлен» (253 % у CatBoost) — из-за **крошечного знаменателя** `₽/м²`: у земли цена за м² на 2–3 порядка ниже, чем у квартир, поэтому маленькая абсолютная ошибка раздувается в гигантский процент. `MAPE = mean(|error| / |y|)` нестабильна при `y → 0`: асимметрична (недооценка ≤ 100 %, переоценка неограничена) и доминируется самыми дешёвыми участками.

## Решение

Добавить в `TrainQuartet` **WAPE** — агрегированный относительный процент, устойчивый к мелкому знаменателю:

- `wape = Σ|y − ŷ| / Σ|y|` — единственный относительный процент, который делится на **сумму** цен, а не на пообъектный знаменатель. Это стандартный «бизнес-процент» (Σ ошибок / Σ цен), сопоставимый между классами. Считается в исходной шкале ₽/м² для **всех** классов.

Отчётная картина для landplot: **Spearman** (ранг) + **WAPE** (агрегированный процент). MAPE для земли по-прежнему считается, но не репрезентативен.

## Откат log-таргета (2026-08-18)

Первоначально ADR-0026 включал также **log-таргет** для landplot: обучать квартет на `y_model = log(y)`, а OOF экспоненцировать обратно. После A/B-сравнения на переобученной модели log-таргет был **откачен** — значимого прироста он не дал:

| метрика (landplot, исходная шкала) | identity | log-target |
| --- | --- | --- |
| WAPE (CatBoost) | 20.85 % | 20.78 % |
| Spearman (CatBoost) | 0.918 | 0.916 |
| WAPE (EBM) | 29.36 % | 31.95 % |

Ранжирование (Spearman) и агрегатная ошибка (WAPE) основной модели не изменились; EBM по WAPE даже чуть ухудшился. Log-таргет лишь перераспределял ошибку в пользу мелких участков, при этом усложнял пайплайн (exp-обратка, `rmse_log`, MAPE в log-шкале) и ломал объяснение EBM по земле (слагаемые оказывались в log-шкале).

## Почему WAPE, а не альтернативы

| Вариант | Почему отвергнут |
| --- | --- |
| Log-таргет | A/B не показал прироста по WAPE/Spearman; усложняет пайплайн и объяснение EBM. |
| MdAPE (медиана APE) | Робастен к выбросам, но знаменатель всё равно мелкий — полумера. |
| Общая целевая метрика только MAE | MAE не относительный — не сопоставим между классами с разным масштабом цены. |

## Влияние

- В `quartet_metrics.json` у каждой модели появляется `wape` (дробь, `Σ|y−ŷ| / Σ|y|`; `NaN`, если сумма цели нулевая).
- Все классы по-прежнему обучаются на исходном таргете (identity); OOF-паркеты и метрики — в ₽/м².
- `mean_mae/rmse/mape` сохраняют исходный смысл (₽/м²) для всех классов, включая landplot.
